# JelajahBanua — Aplikasi Eksplorasi Wisata Kalimantan Selatan

JelajahBanua adalah aplikasi mobile berbasis Flutter yang dirancang untuk membantu pengguna mengenal dan menemukan berbagai destinasi wisata di Kalimantan Selatan. Aplikasi ini menampilkan informasi wisata, foto destinasi, kategori wisata, lokasi, dan estimasi harga tiket masuk dalam antarmuka yang sederhana dan menarik.

Project ini dibuat sebagai bagian dari **Tugas 2 Flutter**, dengan fokus pada perancangan dan implementasi antarmuka pengguna (UI).

---

## 🎯 Tujuan

- Memperkenalkan berbagai destinasi wisata di Kalimantan Selatan.
- Menampilkan informasi wisata dengan tampilan yang menarik dan mudah dipahami.
- Menerapkan materi dasar Flutter yang telah dipelajari di kelas.
- Melatih kemampuan dalam merancang dan mengimplementasikan UI aplikasi mobile.

---

## ✨ Fitur

- **Beranda Wisata** — Menampilkan destinasi wisata pilihan.
- **Kategori Wisata** — Mengelompokkan destinasi berdasarkan jenis wisata.
- **Kartu Destinasi** — Menampilkan foto, nama tempat, lokasi, dan estimasi harga tiket masuk.
- **Detail Wisata** — Menampilkan informasi lebih lanjut mengenai destinasi yang dipilih.
- **Interaksi UI** — Memberikan respons ketika pengguna mengetuk kategori atau kartu destinasi.

> **Catatan:** Informasi destinasi menggunakan data contoh (*dummy*) dan aplikasi berfokus pada tampilan antarmuka. Backend, database, pemesanan tiket, dan integrasi peta belum menjadi bagian dari project ini.

---

## 🛠️ Teknologi

- **Flutter** — Framework untuk pengembangan aplikasi mobile.
- **Dart** — Bahasa pemrograman yang digunakan.
- **Material Design** — Panduan desain antarmuka aplikasi.
- **Visual Studio Code / Android Studio** — Editor untuk pengembangan aplikasi.

---

## 🚀 Cara Menjalankan Project

### Persyaratan
Pastikan perangkat sudah memiliki Flutter SDK dan Android Studio atau Visual Studio Code.

### Langkah-langkah
1. Clone repository atau unduh project ini.
2. Buka folder project di terminal.
3. Jalankan perintah berikut untuk mengunduh dependensi:
   ```bash
   flutter pub get
   ```
4. Jalankan aplikasi:
   ```bash
   flutter run
   ```
> Pastikan emulator atau perangkat Android sudah terhubung sebelum menjalankan aplikasi.
